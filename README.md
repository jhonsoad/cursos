# 🅰️ Módulo Angular

Bem-vindo à branch **`angular`**! Este diretório é focado no aprendizado e desenvolvimento de aplicações webSPA com a plataforma e framework **Angular**.

---

## 📂 Projetos Destacados

### 🏦 `bytebank/`
Aplicação bancária completa construída com Angular, explorando os principais pilares do ecossistema:

- **Componentização**: Divisão da interface em componentes reutilizáveis (formulários, extrato, cabeçalho).
- **Data Binding**: Manipulação de dados com *Property Binding*, *Event Binding* e *Two-Way Data Binding*.
- **Services & Dependency Injection**: Centralização da lógica de negócios e estado das transações usando Serviços.
- **Formulários**: Captura e validação de dados de transferências e depósitos.
- **Pipes**: Formatação de moedas e datas na exibição do saldo e extrato.

---

## 🚀 Como Executar o Projeto

1. Navegue até o diretório do projeto:
   ```bash
   cd bytebank
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```bash
   ng serve
   # ou
   npm start
   ```

4. Abra o navegador em `http://localhost:4200/`.
