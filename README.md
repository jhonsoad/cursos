# ⚙️ Módulo Backend

Bem-vindo à branch **`backend`**! Este diretório é dedicado a projetos, exercícios e experimentos focados no desenvolvimento do lado do servidor (*Server-Side*), utilizando linguagens como **Node.js**, **Java** e **Python**.

---

## 📂 Estrutura de Pastas e Linguagens

Abaixo está a divisão de tecnologias presentes nesta branch:

### 🟩 `Node/`
Aplicação backend construída com Node.js (usando **Fastify**), explorando conceitos de CRUD, rotas HTTP e persistência de dados.
- **Destaques**:
  - `server.js`: Servidor Fastify principal.
  - `database-postgres.js` & `database-memory.js`: Implementação de banco de dados em memória e integração com PostgreSQL.
  - `routes.http`: Arquivo de requisições HTTP para testar os endpoints da API diretamente no editor.

### ☕ `Java/`
Contém projetos básicos e exercícios de introdução ao ecossistema Java.
- **`primeiroprojeto/`**: Exercícios fundamentais (perfil, operações simples de soma/subtração e classes básicas).
- **`SomaSwing/`**: Projeto utilizando a biblioteca Java Swing para construção de interfaces gráficas desktop.

### 🐍 `Python/`
Espaço voltado para rotinas, scripts rápidos e testes conceituais usando a linguagem Python (`teste01.py`).

---

## 🚀 Como executar os projetos

### Node.js (Servidor)
1. Navegue até a pasta do Node:
   ```bash
   cd Node
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
