# Cursos e Projetos de Estudo

Este repositório está organizado em diferentes **branches**, onde cada uma é voltada para um ecossistema, linguagem ou tecnologia específica.

---

## 🌿 Guia de Branches

| Branch | Descrição |
| :--- | :--- |
| 🔀 **`develop`** | Branch de desenvolvimento principal contendo o histórico unificado e integração dos módulos do projeto. |
| 🅰️ **`angular`** | Contém projetos, exercícios e módulos desenvolvidos utilizando a biblioteca/framework **Angular**. |
| ⚙️ **`backend`** | Focada no desenvolvimento do lado do servidor (APIs REST, CRUDs com Node.js, serviços de rede e banco de dados). |
| 💻 **`frontend`** | Dedicada aos projetos e componentes da interface do usuário de forma geral. |
| ⚛️ **`next-js`** | Contém aplicações focadas em **Next.js** (SSR, SSG, roteamento do Next e Ecossistema React). |
| 📘 **`typescript`** | Focada em conceitos, utilitários, tipagens e projetos construídos com **TypeScript**. |

---

## 🛠️ Como navegar entre as branches

Para alternar para uma branch específica no seu ambiente local, execute:

```bash
git checkout <nome-da-branch>
```

Por exemplo:
```bash
git checkout angular
```
