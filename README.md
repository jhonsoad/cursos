# 💻 Módulo Frontend

Bem-vindo à branch **`frontend`**! Este diretório é dedicado ao aprendizado dos fundamentos e conceitos avançados do desenvolvimento Web Client-Side (HTML5, CSS3, JavaScript Web e Testes).

---

## 📂 Estrutura de Conteúdos

### 🟨 `Javascript/`
Projetos práticos focados em manipular o DOM, gerenciar dados no navegador e construir interfaces dinâmicas:
- **`JavaScript_manipulando_o_DOM/`**:
  - `Robotron 2000`: Aplicação para customização de peças de um robô com cálculo dinâmico de atributos.
  - `Fokus-projeto-base`: Timer no estilo Pomodoro para foco, descansos e reprodução de sons com controle de áudio.
- **`JavaScript_na_Web_armazenando_dados_no_navegador/`**:
  - `mochila-de-viagem`: Aplicação de lista de itens persistida localmente no `localStorage`.
- **`JavaScrit_programando_na_linguagem_da_web/`**:
  - `introducao-javascript`: Tabela de cálculo automático de IMC de pacientes, filtros e busca via AJAX.

### 🃏 `Jest/`
Exercícios e projetos práticos de testes automatizados unitários utilizando o framework **Jest**:
- `curso_jest/`: Testes de funções, módulos, mocks de métodos, fábricas de objetos (*PersonFactory*) e asserções.

### 💡 `Logica/`
Exercícios introdutórios de lógica de programação com JavaScript e HTML canvas (`logica_1` e `logica_2`).

---

## 🚀 Como Executar os Projetos

A maioria dos projetos front-end nesta branch são estáticos. Para visualizar:
1. Abra qualquer pasta de projeto (ex: `Javascript/JavaScript_manipulando_o_DOM/-robotron-2000`).
2. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** do VS Code.

Para os projetos com **Jest**:
```bash
cd Jest/curso_jest
npm install
npm test
```
