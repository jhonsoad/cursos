# ⚛️ Módulo Next.js

Bem-vindo à branch **`next-js`**! Este diretório reúne projetos, aplicações e guias práticos desenvolvidos com o framework **Next.js** (Ecossistema React).

---

## 📂 Projetos e Aplicações

### 📚 `fiap-books/`
Aplicação de catálogo de livros desenvolvida utilizando **Next.js (App Router & Pages Router)**, **TypeScript** e **TailwindCSS**.
- **Destaques**: Componentização React, estilização com Tailwind, páginas de listagem e navegação otimizada.

### 📱 `fiap-app-next-js/`
Projeto explorando renderização do lado do servidor (SSR), rotas dinâmicas (`pages/post/[id].js`), estilos globais e componentes de interface.

### ⚡ `Nextjs_tour_pelo_nextjs/`
Série de módulos de estudo guiado divididos por aulas:
- **Aula 03**: *Dynamic Imports*, prefetching de links e navegação entre páginas.
- **Aula 04**: Criação de páginas de erro personalizadas (`404.js`), APIs internas (`pages/api`), `_app.js` e `_document.js`.

### 🚨 `next-error-handling/`
Projeto prático demonstrando boas práticas para tratamento e exibição de erros no Next.js.

### 🛠️ `api-routes-rest-app/`
Construção de APIs REST utilizando as **API Routes** do Next.js com TypeScript e navegação por IDs dinâmicos.

---

## 🚀 Como Executar qualquer Projeto

1. Navegue até a pasta do projeto desejado:
   ```bash
   cd Nextjs/fiap-books
   # ou outro projeto ex: cd Nextjs/fiap-app-next-js
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse `http://localhost:3000` no seu navegador.
